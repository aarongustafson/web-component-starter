esm.sh CDN sanity check

This page loads the component class from esm.sh and registers it manually.

Import and register the class

<script type="module">
  import { ComponentNameElement } from
    'https://esm.sh/@aarongustafson/COMPONENT-NAME@0.0.1/COMPONENT-NAME.js?bundle&target=es2022';

  if (!customElements.get('COMPONENT-NAME')) {
    customElements.define('COMPONENT-NAME', ComponentNameElement);
  }
</script>
