Import and register the class

Import the class from a specific package version, then register the element. The authored paragraph remains visible if JavaScript is disabled or the CDN import fails. The placeholder package won’t load until you name and publish your component. 

<script type="module">
  import { ComponentNameElement } from
    'https://esm.sh/@aarongustafson/COMPONENT-NAME@0.0.1/COMPONENT-NAME.js?bundle&target=es2022';

  if (!customElements.get('COMPONENT-NAME')) {
    customElements.define('COMPONENT-NAME', ComponentNameElement);
  }
</script>
