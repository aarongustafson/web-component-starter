Preserve authored content

Wrap native HTML in the component. The starter leaves this paragraph in the document without adding content or styles. Without JavaScript, the same paragraph remains visible.

Set an example attribute

Set example-attribute to give exampleAttribute a value after registration. Assigning the property updates the attribute; assigning null or undefined removes it. This example doesn’t change the paragraph or its appearance. 

<COMPONENT-NAME example-attribute="value">
  <p>Content with attributes</p>
</COMPONENT-NAME>
