Import and call the registration helper

Use @latest to load the most recently published version. Importing the module registers the element; calling defineComponentName() again leaves that registration in place. The paragraph remains visible without JavaScript or if the import fails. The placeholder package won’t load until you name and publish your component. 

<script type="module">
  import { defineComponentName } from
    'https://unpkg.com/@aarongustafson/COMPONENT-NAME@latest/define.js?module';
  defineComponentName();
</script>
